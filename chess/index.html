Kinetix Review extension

Adds a Review in Kinetix button to finished games on chess.com and lichess.org. One click opens the game here with accuracy, every move graded and plain-English explanations.

Finished games only, never during a live game. No tracking, no account needed.

Download for Chrome
  1. Unzip the download (double-click it). You get a folder.
  2. Open chrome://extensions in the address bar (Edge: edge://extensions, Brave: brave://extensions).
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and pick the unzipped folder.
  5. Optional: pin Kinetix Game Review from the puzzle-piece menu.
Download for Firefox
  1. Keep the zip as it is (don't unzip).
  2. Open about:debugging#/runtime/this-firefox in the address bar.
  3. Click Load Temporary Add-on… and pick the zip.

Firefox removes it when it restarts, so you'd load it again next time.

Shortcut on a game page: Alt+Shift+K. Phones can't run extensions: paste a PGN into Analysis instead.
